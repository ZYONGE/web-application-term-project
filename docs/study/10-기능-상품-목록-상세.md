# 10. 기능 — 상품 목록 · 상세

## 핵심

목록 · 상세 · 조합 맞추기 모두 **"판매중이고 재고 > 0"** 이라는 한 줄 조건(`ProductDAO.ON_SALE`)을 같이 쓴다. 재고가 0 이 되면 자동으로 숨는다.

## 상품 목록

| 단계 | 내용 |
|---|---|
| 화면 | `product/list.jsp` + 카드 `common/prodcard.jsp` |
| 호출 URL | `GET /product/list?categoryId=&type=&keyword=&sort=&page=` |
| 메서드 | `ProductServlet.list()` → `ProductDAO.shopPage(...)` → `DB.page()` |
| SQL | `SELECT … FROM product p … WHERE p.status='판매중' AND p.stock > 0 [AND 카테고리] [AND 이름 LIKE ?] ORDER BY … LIMIT ?, ?` |
| 정렬 | `latest`(기본) · `priceAsc` · `priceDesc` · `rating` · `name` → `ProductDAO.shopOrder()` 가 ORDER BY 문으로 바꿈 (모르는 값은 최신순) |
| 검색 | 트랙은 **구성품 이름으로도** 찾는다 ("오메가" 검색 → 오메가3 가 든 트랙도 나옴) |
| 페이지 | 10개씩. `DB.page()` 가 `COUNT(*)` + `LIMIT` 를 같이 처리해 `Page` 객체로 돌려줌 |

정렬값은 사용자가 보낸 문자열을 SQL 에 그대로 넣지 않고, **정해진 ORDER BY 문 중 하나로만** 바꾼다 → SQL 인젝션 걱정 없음.

## 상품 상세

| 단계 | 내용 |
|---|---|
| 호출 URL | `GET /product/view?productId=` |
| 메서드 | `ProductServlet.view()` |
| 없는 상품 | `ProductDAO.byId(id, true)` 가 null → "판매 중인 상품이 아닙니다" + 목록으로 redirect |
| 화면에 넘기는 것 | 상품, 리뷰 목록, **별점 분포**(리뷰를 직접 셈), AI 요약, 문의, 찜 여부, 금지 조합 안내, 섭취 일수 빠른 버튼 |
| 섭취 일수 | 상한 = `min(재고, MAX_INTAKE_DAYS)`. 첫 값은 30일(또는 상한) |

### 상세 화면에서 일어나는 일

1. 빠른 버튼(7 · 14 · 30 · 60 · 90일) 클릭 → `custom.js` 가 입력칸과 "1포 350원 × 14일 = 4,900원" 합계를 바로 바꿈 (서버 왕복 없음)
2. "장바구니 담기" → `POST /cart/add` (→ 장바구니 노트)
3. 탭(상세 · 표기정보 · 리뷰 · 문의)은 `prodtabs.js`
4. AI 요약은 **저장된 것만 읽는다** (→ AI 노트)

## 역할별 차이

- 관리자가 상세를 보면 구매 폼 대신 "구매는 일반 회원 계정으로만 가능합니다" 가 나온다 (`<c:choose>` 로 분기).
- 비밀 문의는 작성자와 관리자에게만 내용이 보인다 (`BoardDAO.productQna(…, memberId, admin)`).
